# System Normativity Unknown Degradation

This example simulates a system that appears "normal" based on standard monitored metrics (CPU, Memory, Network). However, it also has an unmonitored "internal corruption" level. The simulation demonstrates how the system can actively try to maintain its perceived "normal" operational state (Canguilhem's normativity) even as its internal health degrades due to the unknown factor, highlighting the critical role of unobserved states in system health.

## Language

`python`

## How to Run

Save the code as `system_normativity.py` and run from your terminal: `python system_normativity.py`
